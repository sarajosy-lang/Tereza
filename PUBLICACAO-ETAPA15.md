# TEREZA — Etapa 15

## Hospedagem escolhida para a primeira publicação
GitHub Pages, por ser adequado a um site estático e ter opção no GitHub Free.

## Antes de publicar
1. Criar uma conta/repositório público no GitHub.
2. Enviar os arquivos desta pasta para o repositório.
3. Em Settings > Pages, configurar a publicação a partir da branch principal.
4. Abrir a URL `https://SEU-USUARIO.github.io/SEU-REPOSITORIO/`.
5. Conferir o site no Android e no computador.
6. Só depois definir um domínio próprio, se desejar.

## Importante
O domínio personalizado é opcional. O endereço `github.io` permite começar sem comprar domínio. GitHub Pages suporta HTTPS.

## Conteúdo sensível
Não colocar no repositório dados pessoais, documentos, credenciais, chaves ou informações privadas.

## SITEMAP
Depois que a URL real for escolhida, substituir `SEU-USUARIO.github.io/SEU-REPOSITORIO/` em sitemap.xml pela URL final.

## PWA
O manifest foi incluído para preparar a TEREZA para instalação como atalho/app no navegador. A experiência de instalação pode variar conforme navegador e sistema.
