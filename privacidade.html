Privacidade

A versão informativa da TEREZA foi preparada para funcionar como um site estático. Nesta versão, não há cadastro de usuário nem formulário de coleta de dados pessoais.

Dados e armazenamento

As funcionalidades locais do site podem usar dados temporários do próprio navegador para funcionamento. Não envie informações pessoais, dados de saúde, documentos ou dados sensíveis.

Contato e futuras versões

Se futuramente forem adicionados analytics, formulários, login ou integrações externas, esta política deverá ser revisada antes da ativação desses recursos.
